# 🧮 Calculadora Básica en Python

## Descripción
Proyecto de una calculadora básica desarrollada en Python que permite realizar operaciones matemáticas mediante un menú interactivo.

## Funcionalidades
- Suma.
- Resta.
- Multiplicación.
- División.
- Validación de datos ingresados.
- Manejo de errores.
- Control de división por cero.

## Tecnologías utilizadas
- Python 3
- Funciones
- Condicionales
- Ciclo While
- Match-Case
- Try-Except

## Ejecución

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto en VS Code.
3. Ejecutar:

```bash
python calculadora.py
```
